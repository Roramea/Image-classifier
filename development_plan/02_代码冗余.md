### 问题2: MainPresenter 方法重复包装

**状态**: ✅ 已完成

**修复内容**: 通过 `__getattr__` 动态委托解决：

```python
def __getattr__(self, name):
    if hasattr(self.classification_service, name):
        return getattr(self.classification_service, name)
    if hasattr(self.duplicate_service, name):
        return getattr(self.duplicate_service, name)
    if hasattr(self.classifier, name):
        return getattr(self.classifier, name)
    if hasattr(self.image_cache_service, name):
        return getattr(self.image_cache_service, name)
    raise AttributeError(f"'MainPresenter' object has no attribute '{name}'")
```

**已修改文件**: `presenters/main_presenter.py`

### 问题4: MainWindow 按钮样式重复（P1）

**状态**: ✅ 已完成

**问题描述**

在 `_create_navigation_layout()` 和其他布局方法中，大量按钮创建代码重复，每个按钮需要4-5行代码，相似按钮的创建逻辑完全重复，难以统一修改按钮样式。

**修复内容**: 通过创建两个工厂方法解决：

1. `_create_button()` - 创建 QPushButton，支持自定义背景色、边框色、悬停色、按下色、文字色、字体粗细、内边距、字体大小、禁用状态、快捷键、提示和大小策略

2. `_create_tool_button()` - 创建 QToolButton，支持与 `_create_button()` 类似的参数，额外支持最小宽度、最小高度和固定尺寸

**替换的按钮代码**:
- `_create_left_panel()`: select_btn, restore_hash_dialog_btn, threshold_minus_btn, threshold_plus_btn, storage_btn, theme_btn, settings_btn, add_shortcut_btn, del_shortcut_btn
- `_create_duplicate_group()`: select_all_btn, deselect_all_btn, view_btn, delete_btn
- `_create_right_panel()`: cancel_rename_btn
- `_create_navigation_layout()`: rotate_180_ccw_btn, rotate_ccw_btn, rotate_cw_btn, rotate_180_cw_btn, prev_group_btn, prev_img_btn, next_img_btn, next_group_btn, undo_btn

**已修改文件**: `views/main_window.py`

### 问题5: 哈希列表更新逻辑重复（P2）

**状态**: ✅ 已完成

**问题描述**

在 `MainPresenter` 中，多个方法包含相似的哈希列表更新逻辑。特别是在 `undo_classify` 方法中，存在复杂的哈希列表同步逻辑，与其他地方的列表过滤和更新操作有重复模式。

**修复内容**: 通过创建 `_sync_hash_list_with_groups()` 公共方法解决：

1. `_sync_hash_list_with_groups()` - 同步 hash_list 与当前分组状态，只保留当前分组中存在的图片路径

**优化效果**:
- 将 `undo_classify` 中的复杂列表同步逻辑简化为一行调用
- 统一了哈希列表与分组状态的同步机制
- 提高了代码可读性和可维护性

**已修改文件**: `presenters/main_presenter.py`
