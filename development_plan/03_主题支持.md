```python
class ThemedDialog(QDialog):
    def __init__(self, parent=None):
        super().__init__(parent)
        self._connect_theme_signal()

    def _connect_theme_signal(self):
        theme_manager.theme_changed.connect(self._on_theme_changed)

    @pyqtSlot(object)
    def _on_theme_changed(self, colors):
        self._apply_theme()

    def _apply_theme(self):
        pass

    def _get_colors(self):
        return theme_manager.colors

    def closeEvent(self, event):
        theme_manager.theme_changed.disconnect(self._on_theme_changed)
        super().closeEvent(event)
```

1. **图像显示区域** - `image_label` 的背景样式

3. **状态栏** - `status_bar` 的样式
4. **工具栏按钮** - 部分工具栏按钮样式

#### 影响

- 主题切换时，部分组件保持旧主题颜色
- 用户体验不一致

完善 `MainWindow._apply_theme()` 方法，确保所有组件样式在主题切换时更新：

```python

    c = theme_manager.colors
    
    # 更新主窗口背景
    self.setStyleSheet(f"background-color: {c.window_bg};")
    
    # 更新图像显示区域
    self.image_label.setStyleSheet(f"""
        background-color: {c.canvas_bg};
        border: 2px solid {c.border};
        border-radius: 5px;
    """)
    
    # 更新哈希列表
    self.hash_list.setStyleSheet(f"""
        QListWidget {{
            background-color: {c.list_bg};
            border: 1px solid {c.border};
            border-radius: 3px;
            color: {c.text_primary};
            font-size: 13px;
        }}
        QListWidget::item:hover {{
            background-color: {c.item_hover};
        }}
        QListWidget::item:selected {{
            background-color: {c.item_selected};
        }}
    """)
    
    # 更新状态栏
    self.status_bar.setStyleSheet(f"""
        QStatusBar {{
            background-color: {c.status_bar_bg};
            color: {c.text_primary};
            font-size: 12px;
        }}
    """)
    
    # 更新工具栏按钮样式
    for btn in self.toolbar_buttons:
        btn.setStyleSheet(self._create_tool_button_style())
    
    # 更新旋转按钮样式
    self._update_rotate_button_styles()
```

### 问题6: 主题切换时内存泄漏风险（P2）

#### 问题描述

虽然 `ThemedDialog` 的 `closeEvent()` 方法断开了信号连接，但如果对话框被多次创建和销毁，可能存在以下问题：

1. **信号连接累积** - 如果 `_connect_theme_signal()` 被多次调用
2. **lambda 闭包引用** - 信号回调中的 lambda 可能持有外部对象引用

#### 修复方案

1. 添加信号连接标记，确保只连接一次
2. 使用 `sender()` 或弱引用避免内存泄漏

```python
class ThemedDialog(QDialog):
    def __init__(self, parent=None):
        super().__init__(parent)
        self._theme_connected = False
        self._connect_theme_signal()

    def _connect_theme_signal(self):
        if not self._theme_connected:
            theme_manager.theme_changed.connect(self._on_theme_changed)
            self._theme_connected = True

    def closeEvent(self, event):
        if self._theme_connected:
            theme_manager.theme_changed.disconnect(self._on_theme_changed)
            self._theme_connected = False
        super().closeEvent(event)
```

#### 修改步骤

1. 在 `ThemedDialog` 中添加连接状态标记
2. 修改 `_connect_theme_signal()` 和 `closeEvent()` 方法
3. 测试多次打开/关闭对话框的内存使用情况
